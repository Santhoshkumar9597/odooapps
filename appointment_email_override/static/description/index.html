Appointment Email From Override

This module allows you to set a fixed sender email address for all appointment-related emails in Odoo. By default, Odoo uses dynamic user emails, but this module ensures a consistent and controlled sender identity.

✨ Key Features

  • Set a static "From" email address
  • Override default appointment email sender
  • Works with appointment booking emails
  • Ensures consistent branding
  • Simple and lightweight implementation

⚙️ How It Works

The module overrides the email sending logic in appointment-related actions and replaces the sender email with a predefined static email address.

📌 Use Cases

  • Companies using a central email like info@company.com
  • Avoid exposing employee email addresses
  • Maintain brand consistency in communication
